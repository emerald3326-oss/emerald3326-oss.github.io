# 유쾌한 소정샘의 역사 Class - 설정·배포 방법

구성: **Apps Script 웹 앱 1개**(화면 + 서버) + **구글 시트 "기록" 1개** + **Gemini API** + **노션 DB**
(독도 골든벨과 같은 방식: 시트에서 Apps Script를 열고 웹 앱으로 배포)

## 0. 파일 설명
| 파일 | 용도 |
|---|---|
| `Code.gs` | 서버 코드 (시트 기록, Gemini, 노션 연결) |
| `index.html` | 앱 화면 |

## 1. 기록 시트 열기
1. [유쾌한 소정샘의 역사 Class 기록](https://docs.google.com/spreadsheets/d/11mGWsmflG2aHBZwKcZ7StCyfDskFr_EnLTx74y9M1FE/edit) 시트를 엽니다.
2. 확장 프로그램 → **Apps Script**

## 2. 코드 붙여넣기
1. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs`로 교체
2. 파일 추가(＋) → **HTML** → 이름을 `index` 로 하고 `index.html` 내용 붙여넣기

## 3. 스크립트 속성 (프로젝트 설정 ⚙ → 스크립트 속성)
| 속성 | 값 |
|---|---|
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) 에서 발급한 키 |
| `NOTION_TOKEN` | 노션 통합 시크릿 (아래 4번) |
| `TEACHER_PW` | 선생님 암호 (미설정 시 1234) |

## 4. 노션 연결
1. [notion.so/profile/integrations](https://www.notion.so/profile/integrations) → 새 통합 만들기 → 시크릿 복사 → `NOTION_TOKEN`
2. 노션 `과제 제출` 페이지 우상단 ··· → **연결** → 만든 통합 추가

## 5. 초기화 & 권한 승인
1. 편집기 상단 함수 선택에서 `setup` → ▶ 실행 → 권한 승인 (외부 서비스 연결 허용 포함)
2. 시트에 **"기록"** 탭과 머리글이 만들어졌는지 확인

## 6. 웹 앱 배포
1. 배포 → **새 배포** → 유형 **웹 앱**
2. 다음 사용자로 실행: **나** / 액세스 권한: **모든 사용자**
3. 배포 → 웹 앱 URL 복사 → 학생들에게 QR/링크로 공유
4. 코드를 고친 뒤에는 배포 → **배포 관리 → 편집 → 새 버전 → 배포** (URL 유지)

## 7. 리허설 체크리스트 (수업 전날)
- [ ] 학생 기기 2~3대로 입장 → 달력 → 수업 화면
- [ ] 선생님 🔒 로그인 → 수업 날짜 등록(도입/내용 정리/학습지/활동 링크)
- [ ] AI 보조선생님: 글 질문, 사진 질문 각 1회
- [ ] 보고서 제출 → 노션 `학생 과제 수합표`에 행이 생기는지
- [ ] 손들기 → 선생님 도구에 표시, 발표자 뽑기, 타이머, 배경음악
- [ ] 시트 "기록"에 입장/AI질문/보고서/손들기 행이 쌓이는지
- [ ] 동시 접속 시험: 여러 기기에서 동시에 입장·질문해 보기 (AI 질문은 학생당 5초 간격 제한)
