# 독도 골든벨 - Firebase 버전 설정 방법

구성: **Firebase**(게임 진행·실시간 화면) + **Apps Script**(구글 시트 기록·학습지 드라이브 저장)

## 0. 파일 설명
| 파일 | 용도 |
|---|---|
| `index.html` | 앱 화면 (웹에 올릴 파일) |
| `database.rules.json` | Firebase 보안 규칙 (콘솔에 붙여넣기) |
| `seed.json` | 문제·정답·시트 기록 설정 (**콘솔에 가져오기 후 공개 장소에 올리지 마세요**) |
| `logger.gs`, `worksheet.html` | Apps Script 에 붙여넣기 (시트 기록 + 학습지) |

## 1. Firebase 콘솔 설정 (프로젝트: dokdo-goldenbell)
1. **빌드 → Authentication → 로그인 방법**: `익명` 사용 설정 + `이메일/비밀번호` 사용 설정
2. **사용자** 탭에서 선생님 계정이 있어야 합니다. (기본값 `teacher@dokdo.kr`)
   - 다른 이메일을 쓰면 `index.html` 의 `TEACHER_EMAIL` 과 `database.rules.json` 의 이메일(6곳)을 같은 주소로 바꾸세요.
3. **Authentication → 설정 → 승인된 도메인**에 앱을 올릴 주소의 도메인을 추가합니다. (예: `emerald3326-oss.github.io`)
4. **Realtime Database → 데이터** 탭 → ⋮ → **JSON 가져오기** → `seed.json` 선택 (루트에 가져오기)
5. **Realtime Database → 규칙** 탭 → `database.rules.json` 내용을 붙여넣고 **게시**

## 2. Apps Script (구글 시트 기록 + 학습지)
1. 기록용 구글 시트를 열고 확장 프로그램 → Apps Script
2. `Code.gs` 내용을 `logger.gs` 로 교체, HTML 파일 `worksheet` 에 `worksheet.html` 붙여넣기 (이전 `index` 파일은 지워도 됩니다)
3. 프로젝트 설정 → 스크립트 속성 → `LOG_SECRET` 추가, 값은 `seed.json` 안 `"secret"` 값과 **같게**
4. 편집기에서 함수 `doGet` 실행 → 권한 승인
5. 배포 → 배포 관리 → 편집 → 새 버전 → 배포 (액세스: 모든 사용자). 웹앱 주소가 `index.html` 의 `WORKSHEET_URL`, `seed.json` 의 `log.url` 과 같은지 확인

## 3. 앱 올리기 (둘 중 하나)
- **GitHub Pages**: 저장소 Settings → Pages 에서 배포 브랜치 지정 후 `dokdo-firebase/index.html` 주소로 접속
- **Firebase Hosting**: PC 에서 `npm i -g firebase-tools` → `firebase login` → 이 폴더에서 `firebase deploy --only hosting` → `https://dokdo-goldenbell.web.app`

## 4. 리허설 체크리스트 (전날)
- [ ] 태블릿 2~3대로 입장 → 선생님 로그인 → 문제보기~정답확인 한 바퀴
- [ ] 정답자 수·탈락 처리, 다음 문제 진행
- [ ] 구글 시트 "기록" 에 입장/답안/결과 행이 생겼는지
- [ ] "대회 초기화" 후 처음부터 다시 시작되는지
- [ ] 선생님 태블릿은 대회 내내 켜 두고 인터넷 유지 (채점·기록은 선생님 화면이 합니다)
